وجبة 1: الإفطار

طبق كبير أرز مصري بالسمن + طبيخ خضار بالشوربة + 3 بيضات مقلية بسمن بلدي أو بروتين.

وجبة 2: سناك الظهر

حبتان بطاطا حلوة مهروسة بالسمن البلدي والعسل والسمسم، أو أرز دافئ مع طحينة خام.

وجبة 3: الغداء

طبق كبير أرز أو مكرونة + بروتين متاح (سمك مشوي، فراخ، أو بيض) + بطاطا مشوية.

وجبة 4: العشاء (بدون عيش)

طبق أرز صغير ببيض مقلي، أو فول بالليمون ومعلقتين كبار طحينة سمراء (بديل الكالسيوم).
