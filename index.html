وجبة 1: الإفطار الأساسي

طبق كبير أرز مصري بالسمن + طبيخ خضار بالشوربة (بدون شطة أو فلفل) + 3 بيضات مقلية بسمن بلدي أو قطعة بروتين.

وجبة 2: سناك الظهر عالي السعرات

حبتان بطاطا حلوة مهروسة بالسمن البلدي والعسل الأسود والسمسم، أو طبق أرز دافئ مع طحينة خام.

وجبة 3: الغداء المتكامل

طبق كبير أرز أو مكرونة + بروتين متاح (سمك مشوي، فراخ، كبدة، أو بيض) + حبة بطاطا حلوة مشوية.

وجبة 4: العشاء ودعم الكالسيوم (بدون عيش)

طبق أرز صغير ببيض مقلي، أو طبق فول بالليمون ومعلقتين كبار طحينة سمراء بالمعلقة (بديل ممتاز لكالسيوم اللبن).
